# StoneAge Online v0.1-17

## Party chat

New protocol:

- `0x0B09 PartyChatRequest`
- `0x0B0A PartyChatBroadcast`

The request contains only UTF-8 chat text. The server resolves CharacterId and character name from the authenticated world session and sends the message only to current party members.

## Party management

New protocol:

- `0x0B0B PartyKickRequest`
- `0x0B0C PartyKickResponse`
- `0x0B0D PartyLeaderTransferRequest`
- `0x0B0E PartyLeaderTransferResponse`

Rules:

- only the current leader can kick a member
- only the current leader can transfer leadership
- the target must be a current member of the same party
- the leader cannot target themselves
- kicked members receive an empty PartyState
- remaining members receive a new authoritative PartyState
- if kicking leaves only the leader, the party is automatically dissolved

## Party presence

New unsolicited protocol:

- `0x0B0F PartyPresenceBroadcast`

Payload:

- CharacterId Int64
- Online Byte
- MapId Int32
- X Int16
- Y Int16
- Direction Byte

Presence is emitted from authoritative World runtime state on:

- EnterWorld
- successful Move
- disconnect before party cleanup

Only party members receive the presence packet.

## TestClient

New commands:

- `psay <text>`
- `pkick <characterId>`
- `pleader <characterId>`

`PartyChatBroadcast`, `PartyStateBroadcast`, and `PartyPresenceBroadcast` are handled by the permanent background receive loop.
