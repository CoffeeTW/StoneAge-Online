# StoneAge Online v0.1-16

## Social foundation

Server Hello: `StoneAge Online v0.1-16`.

### Map chat

- `0x0A01 ChatSayRequest`
- `0x0A02 ChatSayBroadcast`

Request payload:

```text
TextLength UInt16
Text UTF-8
```

Rules:

- player must be `InWorld`
- text must be 1-200 UTF-8 bytes
- control characters are rejected
- server derives sender CharacterId and Name
- broadcast is limited to players currently on the sender's map

Broadcast payload:

```text
CharacterId Int64
NameLength UInt16
Name UTF-8
TextLength UInt16
Text UTF-8
```

## Party runtime

Parties are runtime-only in v0.1-16 and are not persisted to PostgreSQL.

Rules:

- maximum 5 members
- invitation lifetime 60 seconds
- only a party leader can invite when already in a party
- target must be online and on the same map
- target cannot already belong to a party
- leader leaving transfers leadership to the next member
- a party automatically dissolves when only one member remains
- disconnect automatically leaves the party and updates remaining members

### Party protocol

- `0x0B01 PartyInviteRequest`
- `0x0B02 PartyInviteResponse`
- `0x0B03 PartyInviteNotification`
- `0x0B04 PartyAnswerRequest`
- `0x0B05 PartyAnswerResponse`
- `0x0B06 PartyStateBroadcast`
- `0x0B07 PartyLeaveRequest`
- `0x0B08 PartyLeaveResponse`

`PartyInviteRequest` carries one `Int64 TargetCharacterId`.

`PartyAnswerRequest`:

```text
InviterCharacterId Int64
Accept Byte (0 reject, 1 accept)
```

`PartyStateBroadcast` is server-authoritative:

```text
PartyId Guid (16 bytes)
LeaderCharacterId Int64
MemberCount Byte
repeated MemberCount times:
  CharacterId Int64
  NameLength UInt16
  Name UTF-8
```

A state with `Guid.Empty`, LeaderId `0`, and MemberCount `0` means the client is no longer in a party.

## TestClient

New commands:

```text
say <text>
pinvite <characterId>
paccept <inviterId>
preject <inviterId>
pleave
```

Chat, party invitations, and party state changes are unsolicited packets and are displayed by the existing background receive loop.

## Follow-up

Party battle, party chat channel, kicking members, explicit leadership transfer, and cross-map party presence are intentionally deferred to later versions.
