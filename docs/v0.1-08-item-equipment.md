# StoneAge Online v0.1-08

## Scope

Item Use + Equipment System.

## Inventory

- 20 stack slots per character.
- Every `character_items` row has a persistent `Slot`.
- `EquippedSlot` is nullable and uses:
  - `1` Weapon
  - `2` Armor
  - `3` Accessory
- One equipped item per equipment slot.
- Equipped items remain in their inventory slot and cannot be sold until unequipped.

## Item effects

- Small Herb: restore 30 HP.
- Stone Fruit: restore 20 MP.
- Wooden Club: Weapon, +3 attack.
- Hide Vest: Armor, +3 defense.
- Bone Charm: Accessory, +2 agility.

Base stats are preserved in the character row. Equipment bonuses are calculated from equipped item definitions so equipping/unequipping does not permanently mutate base attributes.

## Protocol

- `0x0703 ItemUseRequest` / `0x0704 ItemUseResponse`
- `0x0705 EquipmentListRequest` / `0x0706 EquipmentListResponse`
- `0x0707 ItemEquipRequest` / `0x0708 ItemEquipResponse`
- `0x0709 ItemUnequipRequest` / `0x070A ItemUnequipResponse`

Item-use/equip requests identify a persistent inventory row by `Int64 inventoryId`. Unequip identifies the equipment slot by one byte.

## Server-side rules

- Item must belong to the current character.
- Consumables cannot be used while equipped.
- Consumables are only consumed when they have an actual HP/MP effect.
- Equipment item must match a defined equipment slot.
- Equipment quantity must be exactly one.
- Equipping a new item in the same slot automatically unequips the previous item atomically.
- Inventory capacity and stack limits are enforced server-side.
- Shop purchase allocates the first free inventory slot.

## v0.1-08 acceptance

1. Existing development DB upgrades without deleting the PostgreSQL volume.
2. Character inventory exposes slot and equipment state.
3. Inventory cannot exceed 20 occupied stack slots.
4. Small Herb restores HP but never beyond MaxHp.
5. Stone Fruit restores MP but never beyond MaxMp.
6. Consumable is not consumed when HP/MP is already full and it would have no effect.
7. Wooden Club can only occupy Weapon.
8. Hide Vest can only occupy Armor.
9. Bone Charm can only occupy Accessory.
10. Equipping a second item to a slot replaces the previous equipment state safely.
11. Equipped items cannot be sold.
12. Equipment list returns effective attack/defense/agility values.
