# StoneAge Online v0.1-05

## Multiplayer Presence + Collision + Network Health

### Included
- PlayerEnterBroadcast / PlayerLeaveBroadcast
- Map 1000 blocked-tile collision sample
- Direction convention: 0=N, 1=NE, 2=E, 3=SE, 4=S, 5=SW, 6=W, 7=NW
- 120 ms minimum movement interval
- Ping / Pong echo
- 90 second idle timeout
- 30 second periodic online-position autosave
- Disconnect position persistence remains enabled

### Notes
Collision is currently represented by blocked runtime tiles. It is intentionally isolated behind `GameMap.IsWalkable` so a later map-file loader can replace the sample data without changing movement handlers.
