# StoneAge Online v0.1-07

## Item / Inventory / Shop

### Item data

Static item definitions are loaded from `data/items/items.json`.

Initial items:

- 20001 Small Herb
- 20002 Wooden Club
- 20003 Stone Fruit

### Persistent character state

- `characters.Stone`: character currency, default 1000
- `character_items`: persistent stacked inventory
- unique `(CharacterId, ItemId)` row per stack

### Opcodes

- `0x0701 InventoryListRequest`
- `0x0702 InventoryListResponse`
- `0x0710 ShopListRequest`
- `0x0711 ShopListResponse`
- `0x0712 ShopBuyRequest`
- `0x0713 ShopBuyResponse`
- `0x0714 ShopSellRequest`
- `0x0715 ShopSellResponse`

### Shop security

`ShopListRequest` payload:

- Int32 npcId

`ShopBuyRequest` / `ShopSellRequest` payload:

- Int32 npcId
- Int32 itemId
- Int32 quantity

The server validates that:

1. the session is in-world;
2. the NPC exists;
3. NPC type is `shop`;
4. NPC and player are on the same map;
5. player is within one tile of the NPC;
6. item exists in the server item catalog;
7. quantity is positive;
8. buy price / sell price comes from server data;
9. stack limits are enforced;
10. currency and inventory mutations are committed in one database transaction.

### Initial shop NPC

`10003 Village Item Merchant` at Map 1000 `(48,50)`.

### Database upgrade

During v0.1 development, startup executes an idempotent schema upgrade for the new Stone and inventory schema after `EnsureCreated`. Before v1.0 this should be replaced with versioned EF Core migrations.
