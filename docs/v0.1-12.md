# StoneAge Online v0.1-12

## Pet battle expansion

- Agility-based initiative each turn
- Monster can target player or active pet
- Active pet HP is persistent and can reach 0 (KO)
- KO pets stop acting for the remainder of battle
- Pet skill slots are persisted per pet instance
- Initial data-driven pet skills: Bite, Guard Rush, Aqua Fang
- Captured pets learn Bite in slot 0
- Active pet uses its first skill automatically when it obeys
- Pet skill power modifies damage and can override attack element
- BattleStart includes active pet primary skill id
- BattleTurnResult includes player HP, pet HP, monster HP and monster target
- Escape persists current player/pet HP

## Initiative

Each turn creates an initiative list from the living Player, Pet and Monster. It is ordered by Agility, with a random tie-breaker.

## Monster targeting

When a living active pet exists, the monster has a 35% chance to target it. Otherwise it targets the player. Defend only reduces damage when the player is the target.

## Pet skills

Pet skills are stored in `character_pet_skills` with a unique `(CharacterPetId, Slot)` constraint. Skills are attached to the captured pet instance instead of being hard-coded to the monster species.
